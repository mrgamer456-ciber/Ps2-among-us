# Meu jogo 3D com PS2SDK + gsKit

Projeto independente de aprendizado para criar um jogo 3D de PlayStation 2 usando C++ com PS2SDK e gsKit.

Esta pasta fica separada do projeto Among Us (que usa Tyra). Os arquivos do Among Us não devem ser alterados por este projeto.

## Etapas

- [ ] Criar primeiro ELF de teste

- [ ] Criar geometria 3D
- [ ] Aplicar texturas
- [ ] Ler controle do PS2
- [ ] Criar câmera e movimentação
