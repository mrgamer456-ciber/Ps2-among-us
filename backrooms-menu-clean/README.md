# Backrooms — Menu Clean v1

Projeto independente e refeito do zero para testar somente o menu do PS2.
Não inclui código do jogo, áudio, USB, inimigos ou fase.

O workflow copia a imagem original de `tyrarooms/assets/menu/main.tga` para `assets/main.tga`, gera o cabeçalho da textura e compila um ELF separado.

Controles: direcional para navegar, X selecionar, O voltar.
